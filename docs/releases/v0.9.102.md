# v0.9.102

## Highlights

- Added app-wide language and locale support across the app, including UI language, regional formatting, and AI response language preferences.
- Upgraded the runtime and build baseline to Electron 42, Node.js 22, Electron Builder 26, Vite 7, Vitest 4, Playwright 1.60, and `ws` 8.21.
- Hardened Electron navigation and external URL handling with a renderer CSP, safe external URL allowlist, and blocked unexpected renderer navigation.
- Added automated QA coverage for release confidence: runtime baseline checks, GitHub Actions CI, Playwright Electron smoke tests, fake SSH fixtures, Docker-backed OpenSSH E2E coverage, and packaged macOS smoke tests.
- Refreshed package/release automation, release test documentation, and update-feed generation across macOS, Linux, and Windows assets.

## Security And Reliability

- Upgraded Electron off the older v33 line and refreshed supporting build tooling for the current runtime baseline.
- Updated vulnerable runtime dependency coverage, including `ws`.
- Added `npm run test:runtime-baseline`, `npm run test:audit:runtime`, and `npm run test:audit:all` as explicit release gates.
- Added centralized safe external URL handling and tests.
- Added a restrictive renderer `Content-Security-Policy`.
- Blocked unexpected renderer navigation in the main process.

## Testing And Release Automation

- Added `.github/workflows/ci.yml` for PR/push validation.
- Upgraded the release workflow to Node.js 22.
- Added Playwright Electron E2E coverage for launch, isolated state, local project persistence, and SSH workspace validation.
- Added a deterministic fake `ssh` fixture for fast IPC/UI tests.
- Added Docker OpenSSH E2E scaffolding for real SSH handshake coverage on capable CI runners.
- Added macOS packaged-app smoke coverage via `npm run test:package:mac:arm64`.
- Added release and testing plans in `docs/IMPLEMENTATION_PLAN.md`, `docs/TESTING_PLAN.md`, and `docs/RELEASE_TEST_MATRIX.md`.

## Packaging And Update Feeds

- Updated Electron Builder configuration for v26 compatibility.
- Added Linux desktop-name synchronization metadata.
- Fixed Linux update-feed generation so both `amd64`/`x86_64` and `arm64` artifacts are represented correctly.
- Generated refreshed update feeds:
  - `latest-mac.yml`
  - `latest-linux.yml`
  - `latest.yml`
