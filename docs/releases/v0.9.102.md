# v0.9.102

All changes since `v0.9.100`. (v0.9.101 and an earlier v0.9.102 draft were never published, so they are included here.)

## Highlights

- **TerminallySKILL now speaks your language.** The whole app is available in 19 languages: English (US and UK), Arabic, Chinese (Simplified and Traditional), Dutch, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Polish, Portuguese (Brazil and Portugal), Russian, Spanish, Turkish and Ukrainian. Choose a UI language, a regional format for dates and numbers, and the language AI answers in, under Settings → General → Language & Locale. Native menus, the close-window dialog, starter-pack scripts and common error messages follow the same setting.
- **Explain & fix.** When a command fails, one click asks your AI provider what went wrong and suggests a corrected command. Suggestions are inserted at the prompt for you to review. They never run on their own.
- **Interactive programs just work.** Keystrokes now go straight to full-screen and interactive programs (`vim`, `less`, `python3`, `ssh` sessions, password prompts) instead of the type-ahead queue.
- **Safer data.** Projects, scripts, snippets, runs, settings and secrets are saved atomically. A damaged file is now set aside as `*.corrupt-<timestamp>.json` instead of silently replacing your data with an empty file, and saved secrets that can't be decrypted on this machine are kept rather than dropped.
- **Electron 42 baseline.** Upgraded from Electron 33 to Electron 42 with Node.js 22, Electron Builder 26 and Vite 7, plus a renderer Content-Security-Policy and stricter navigation and external-link handling.

## Terminal

- New terminals no longer open blank if the shell integration fails to load. Startup output is shown after a short timeout.
- Fixed zsh reporting `job table full or recursion limit exceeded` when TerminallySKILL was launched from one of its own terminals.
- Your own zsh `ZDOTDIR` and bash `DEBUG` traps are now preserved alongside TerminallySKILL's shell integration.
- Faster handling of large, fast output, and quicker PATH probing when looking up commands.

## Workflows and scripts

- Workflow steps now wait until the terminal for their target machine is ready, so steps no longer run on the wrong machine (for example locally instead of over SSH).
- Step results are tracked with tagged markers, so each step's exit code is attributed to the right step.
- Script selector: "Create new script" is shown as soon as you start typing, Enter creates it, and Save is only enabled when the selection has changed.

## AI

- Requests to AI providers now time out instead of hanging: 90 seconds for cloud providers, 5 minutes for local Ollama and LM Studio models.
- Anthropic requests use larger output limits for long tasks such as command-tree and script generation, so answers are no longer cut off.

## Command builder

- The `--help` parser understands more real-world help layouts (option descriptions on the next line, `--opt=VALUE`, bare type words such as `NUM`, wrapped descriptions). For example, `rg` went from 0 to 101 detected flags.

## Updates

- Update release notes are shown as formatted, collapsible sections in the startup banner and in Settings.

## Security and reliability

- Only one copy of the app runs at a time, so two windows can't overwrite each other's saved data. Opening it again focuses the existing window.
- Added centralized safe external URL handling, a restrictive renderer Content-Security-Policy, and blocking of unexpected renderer navigation.
- Updated vulnerable runtime dependencies, including `ws`.

## Testing and release automation

- CI now runs on `main` and `staging` and includes a TypeScript type-check, unit tests, the i18n completeness check and a production build.
- Added Playwright Electron end-to-end tests, a fake SSH fixture, Docker OpenSSH end-to-end coverage, and a packaged macOS smoke test.
- GitHub workflows upgraded to Node 24-backed actions. Release notes are published from this file.
- Fixed macOS notarization for Electron Builder 26, and Linux update feeds now include both x64 and arm64 builds.

## Known limitations

- Translations were produced with machine assistance and checked for consistency and placeholders. Native-speaker review is welcome; please report wording issues.
- Right-to-left layout for Arabic has not been fully reviewed.
- Help text parsed from `--help` output and the descriptions of commands you add stay in the tool's own language.
- Windows builds are still a work in progress.
