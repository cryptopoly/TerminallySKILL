# v0.9.105

All changes since `v0.9.104`.

**No telemetry. No analytics. No account.** Nothing in TerminallySKILL phones home. The only network use is the update check and the AI providers, SSH and VNC hosts you choose.

## Highlights

- **Quad split.** Four terminals in one 2x2 grid, beside the split buttons, in the command palette or with Cmd+Shift+G (Ctrl+Shift+G on Windows and Linux). It uses your open tabs first and opens new terminals for the rest. Drag the dividers (or where they cross) to resize; click a pane or press Cmd+] / Cmd+[ to move between panes. It works in the docked and the maximised terminal, each project remembers it, and with Reopen terminal tabs on, the next launch brings back the four tabs. Leaving quad goes back to your previous layout without closing a terminal. In a window too small for four panes, only the focused one shows until there is room again.
- **Command blocks.** Each finished command gets a small dot at the right edge of its line: green if it succeeded, red if it failed. Click it to copy the output, copy the command, run it again (it fills the prompt and leaves Enter to you) or ask AI to explain it. Full-screen programs such as `vim` or `htop` get no dot.
- **Reopen your terminal tabs (opt-in).** Turn on Settings → General → Reopen terminal tabs, and the next launch brings back each project's local tabs, the split and the folder each tab was in. SSH and VNC tabs are not reconnected, and old output is not kept. Off by default.
- **A compact terminal footer.** Folder, last command, exit code and chips now sit on one short line. In narrow panes and splits it shrinks to icons, so nothing overlaps.
- **Click the folder to change it.** The footer folder opens a folder picker and types the `cd` for you. Its menu shows the folder in Finder, File Explorer or your file manager, or copies the path.
- **PowerShell on Windows now works like zsh and bash.** TerminallySKILL now sees each command and its exit code in PowerShell. On Windows that turns on command block dots, running, done and needs-you alerts, the password chip, workflow steps, the footer folder and reopening tabs in their folder. Your profile and custom prompt (oh-my-posh, starship) are kept, and it works under the default execution policy without loosening it.
- **A slimmer editor prompt.** The editor prompt is now a single 32px row (it was about 117px). Suggestions show inside that row only while there is one, so the terminal no longer jumps as you type.
- **An AppImage for Linux arm64.** It uses the static AppImage runtime, so it no longer needs `libz.so` or `libfuse2` on the system.
- **A smaller password indicator.** Password prompts (sudo, SSH) show a small chip in the footer instead of a large banner over the terminal, so no line is hidden. It clears after you press Enter.

## Fixes

- Scrolling up during fast output now holds your place, and scrolling back to the bottom follows the output again. Before, the view could stick to the top once the scrollback was full.
- Clicking into the other pane of a split always moves the focus there. On Linux a click could be lost while the pane redrew.
- In a split, Cmd+] / Cmd+[ now moves the keyboard to the other pane too, not only the focus line. Cmd+F and Cmd+Shift+S act on the focused pane only, where both panes used to open search or take a snapshot.
- Quitting while a terminal was still closing could make the app quit unexpectedly (a crash report on macOS). Quit now waits briefly for shells to end.
- "Open in Runs & Logs" from a missed-run alert could jump back to the Dashboard a moment later. A delayed layout save no longer overwrites the tab you just opened.
- Double-clicking a VNC connect button could open two viewers and send the password twice. Extra clicks are now ignored while a viewer starts.
- Resizing a terminal right after its shell exited could crash the app with an error dialog. It is now ignored.
- On Windows, commands the app types now use PowerShell syntax: workflow step results, SSH launch commands, the footer's change of folder, the file viewer's Run button and command builder quoting. Before, they used shell syntax that PowerShell does not understand.
- On Windows, terminals now run on the ConPTY bundled with node-pty (conpty.dll and OpenConsole.exe) instead of the one built into Windows, which could deliver command block markers a line early. Set `TSK_CONPTY_DLL=0` to go back to Windows' own ConPTY.
- On small windows the terminal panel keeps room for about 10 rows. At 1024x677 with the editor prompt on it could shrink to one row.
- When a terminal cannot open (Run Script, New Terminal, snippets, schedules), an error message now says why. Before, nothing happened.
- Linux packages now get correct file permissions whatever the build machine's umask is.
- With macOS's built-in bash 3.2, part of a workflow step's hidden marker command could show in the terminal. It is now always hidden.
- File search without ripgrep returned paths with mixed `/` and `\` on Windows. It now uses Windows separators.
- The "folder already used by another project" warning no longer fires for SSH projects on other hosts, SSH projects with no folder, or a local folder that only shares a path with a remote one.

## Requirements

- macOS 13 or later.
- Windows 10 1903 or later. PowerShell integration needs PSReadLine to see commands as they start; without it, exit codes and folders still work.

## Testing

- 589 unit tests, the type-check and the i18n check pass on macOS, Ubuntu and Windows.
- On macOS arm64, 39 Electron end-to-end tests pass, including the new command block, footer folder, scroll, password chip and session restore tests, plus the local SSH tests. 10 are skipped.
- On Ubuntu arm64 (VM), the full suite passes, including local SSH, Docker SSH, a real x11vnc server, and AppImage and `.deb` package checks.
- On Windows 11 arm64 (VM, Windows PowerShell 5.1) and on GitHub's Windows x64 runner, the end-to-end tests pass with PowerShell (36 passed on the VM). 13 are skipped, mostly SSH, Docker and packaged-app tests that need Linux or macOS fixtures.
- A macOS arm64 test build was hand-tested: command blocks, footer, folder picker, scrolling during fast output and the password chip.

## Known limitations

- Session restore reopens local shells only. Running programs, SSH and VNC tabs, and scrollback are not restored.
- With several windows open, all their tabs reopen in one window, and only the first window's split comes back.
- A tab's folder is the one its shell last reported at a prompt. Shells without TerminallySKILL's shell integration reopen in the folder they started in.
- Agents that do not report their state through OSC 7501, such as Codex, stay orange rather than grey while idle.
- With `TSK_CONPTY_DLL=0` (Windows' own ConPTY), "Copy output" can return only the first line of a command's output.
- On Windows, programs cannot read the terminal's reply to the OSC 7501 support query (Windows' terminal layer drops it), so agents there fall back to plain notifications.
- PowerShell in Constrained Language Mode cannot load the integration; the terminal still works, without dots or alerts.
- Windows, Linux x64 and macOS Intel builds were not hand-tested.
- Translations are machine-assisted.
