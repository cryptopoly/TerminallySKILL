# v0.9.105

All changes since `v0.9.104`.

**No telemetry. No analytics. No account.** Nothing in TerminallySKILL phones home. The only network use is the update check and the AI providers, SSH and VNC hosts you choose.

## Highlights

- **Command blocks.** Each finished command gets a small dot at the right edge of its line: green if it succeeded, red if it failed. Click it to copy the output, copy the command, run it again (it fills the prompt and leaves Enter to you) or ask AI to explain it. Full-screen programs such as `vim` or `htop` get no dot.
- **Reopen your terminal tabs (opt-in).** Turn on Settings → General → Reopen terminal tabs, and the next launch brings back each project's local tabs, the split and the folder each tab was in. SSH and VNC tabs are not reconnected, and old output is not kept. Off by default.
- **A compact terminal footer.** Folder, last command, exit code and chips now sit on one short line. In narrow panes and splits it shrinks to icons, so nothing overlaps.
- **Click the folder to change it.** The footer folder opens a folder picker and types the `cd` for you. Its menu shows the folder in Finder, File Explorer or your file manager, or copies the path.
- **A smaller password indicator.** Password prompts (sudo, SSH) show a small chip in the footer instead of a large banner over the terminal, so no line is hidden. It clears after you press Enter.

## Fixes

- Scrolling up during fast output now holds your place, and scrolling back to the bottom follows the output again. Before, the view could stick to the top once the scrollback was full.
- Clicking into the other pane of a split always moves the focus there. On Linux a click could be lost while the pane redrew.
- Resizing a terminal right after its shell exited could crash the app with an error dialog. It is now ignored.
- The "folder already used by another project" warning no longer fires for SSH projects on other hosts, SSH projects with no folder, or a local folder that only shares a path with a remote one.

## Requirements

- macOS 13 or later.

## Testing

- 535 unit tests, the type-check and the i18n check pass.
- On macOS arm64, 39 Electron end-to-end tests pass, including the new command block, footer folder, scroll, password chip and session restore tests, plus 6 local SSH tests. 10 are skipped.
- On Ubuntu arm64 (VM), the full suite passes, including local SSH, Docker SSH, a real x11vnc server, and AppImage and `.deb` package checks.
- A macOS arm64 test build was hand-tested: command blocks, footer, folder picker, scrolling during fast output and the password chip.

## Known limitations

- Session restore reopens local shells only. Running programs, SSH and VNC tabs, and scrollback are not restored.
- With several windows open, all their tabs reopen in one window, and only the first window's split comes back.
- A tab's folder is the one its shell last reported at a prompt. Shells without TerminallySKILL's shell integration reopen in the folder they started in.
- Agents that do not report their state through OSC 7501, such as Codex, stay orange rather than grey while idle.
- Windows, Linux x64 and macOS Intel builds were not hand-tested.
- Linux arm64 is a `.deb` only.
- Translations are machine-assisted.
