# v0.9.104

All changes since `v0.9.103`.

**No telemetry. No analytics. No account.** Nothing in TerminallySKILL phones home. The only network use is the update check and the AI providers, SSH and VNC hosts you choose.

## Highlights

- **Know when an agent is waiting for you.** Coding agents and other programs can now reach you through the terminal bell, and a terminal that goes quiet at an approval prompt raises "needs you", with a desktop notification. If you stay away, reminders follow at 10 and 30 minutes. No keyboard or mouse input for 2 minutes counts as away, even with the window in front.
- **Clearer tab dots.** Orange ring while running, pulsing yellow when it needs you, green finished, red with a cross failed, grey when an agent says it is idle. A legend is in Help.
- **Maximise the terminal.** `Cmd+Shift+M` (`Ctrl+Shift+M` on Windows and Linux), a tab bar button or the command palette. The same action restores the previous size.
- **Cycle projects from the keyboard.** `Cmd+Option+Down` and `Cmd+Option+Up` on macOS, `Ctrl+Alt+PageDown` and `Ctrl+Alt+PageUp` on Windows and Linux.
- **Keep notifications until dismissed.** A new choice in Settings → General → Notifications. On Windows and Linux it is a toggle. On macOS the system decides, so Settings opens System Settings for you.
- A one-time tip after your first notification explains how to keep notifications on screen until you close them.

## Fixes

- **Workflow steps no longer complete early.** A long step could show as completed while still running, and the next step was typed early. In 0.9.103 this could run later steps after a failed one. Upgrade if you run workflows with long steps.
- zsh history now goes to your real history file. Before, each tab kept its history in a temporary folder, so new tabs did not see old commands.
- The hidden workflow step marker no longer shows in the terminal or enters shell history, including when it wraps at the window edge. In a very narrow window it can still show; this is cosmetic.
- No desktop notification after you stop a command yourself (Ctrl+C or a terminate signal), or while the app quits.
- Secret masking now also catches URL passwords with an empty user (`redis://:pass@host`), `DB_PASS` and `*_PWD` style names, and random-looking values for names ending in `KEY`.
- Terminals now report `TERM_PROGRAM=TerminallySKILL` rather than inheriting the value from whatever started the app, so agents use the right alert path.
- Release packages now hold only the built app and its production dependencies. Source, docs and test files no longer ship.
- Electron 45.2.1 (Chromium 156.0.8078.75) and in-range dependency updates. `npm audit --omit=dev` reports 0 vulnerabilities. `npm audit` reports 15 moderate issues in build tools only, which are not shipped.
- VNC servers that need a password now show the password prompt. Before, the viewer showed "Connection lost" and never asked. A wrong password now asks again.
- Ctrl+R now opens your shell's history search when the editor prompt is on.

## Requirements

- macOS 13 or later.

## Testing

- 523 unit tests, a type-check (now including test files) and the i18n check pass. On macOS arm64, 31 Electron end-to-end tests pass and 6 are skipped, and the packaged app passes the smoke test.

## Known limitations

- Agents that do not report their state through OSC 7501, such as Codex, stay orange rather than grey while idle.
- On macOS, a dev run of the app (ad-hoc signed) showed the dots but no banner, while the signed app notified. Test notifications in a packaged build.
- Pressing Cmd+Q in a dev app started by a script exits with code 0, so it still counts as a normal finish and notifies.
- Windows, Linux x64 and macOS Intel builds were not hand-tested.
- Linux arm64 is a `.deb` only.
- Translations are machine-assisted.
