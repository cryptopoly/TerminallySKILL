# v0.9.103

All changes since `v0.9.102`.

**No telemetry. No analytics. No account.** Nothing in TerminallySKILL phones home. The only network use is the update check and the AI providers, SSH and VNC hosts you choose. The new Privacy tab shows exactly what has left your computer this session.

## Highlights

- **Welcome tour.** First launch only: a short guided tour starts at Create Project and lights up each main screen (Commands, Scripts, Snippets and Files, Logs and Search, New Terminal, Help and Settings). Skip any time; reopen it from Help → How to use TerminallySKILL ("Show welcome tour") or the command palette. Translated into every language.
- **Attention alerts.** Start a long command, switch to another tab or app, and get a green dot when it succeeds or a red dot when it fails, plus a dock badge and a desktop notification when the window is not in front. Workflow approvals pulse amber. Short commands and the terminal you are looking at stay quiet. Settings → General → Notifications.
- **Works with coding agents.** Terminals running Claude Code, Codex and other agents raise the same dots through standard terminal notifications (OSC 9, OSC 777 and OSC 7501 status codes).
- **Jump to the terminal that needs you.** `Cmd+Shift+J` (`Ctrl+Shift+J` on Windows and Linux) opens the terminal that has waited longest, in any project. Also in the command palette and Help → Keyboard Shortcuts.
- **Scheduled workflows.** Run a workflow on an interval or daily at a set time, on chosen weekdays. Each schedule keeps a history of its last 20 runs with a link to the run, and an optional "Run once on launch if a run was missed". Schedules run while the app is open. Open it from the clock icon in the Scripts list.
- **Privacy tab and secret masking.** Settings → Privacy lists what can leave your computer and the hosts contacted this session. Well-known secret formats (GitHub, AWS, Anthropic and OpenAI-style keys, JWTs, private keys, passwords in URLs and `--password` style flags and more) are hidden in saved logs, run records and every AI request. The live terminal is never changed. This reduces accidental leaks; it is not a guarantee, and unknown formats are not caught.
- **Electron 45.** Upgraded from Electron 42 (which stopped getting security fixes on 2026-10-21) to Electron 45.1.0, with Node.js 24 and Chromium 156. Dependencies updated; `npm audit` reports 0 vulnerabilities.
- **Faster start, four new themes.** Only your language loads at start-up. Four in-between themes (Slate, Plum, Dove, Clay) bring the total to 12, and Settings → Theme shows a live preview of each.

## Other changes

- Scripts can run with no project open again: Run Script did nothing when no project was selected. They run in a new terminal in your home folder.
- Workflows no longer hang after a step that runs `sudo` or `apt`: the step now finishes when its command finishes.
- The Linux arm64 `.deb` now has a working terminal (an earlier build shipped an x86 terminal module).
- Only the pane you are working in counts as watched in split view, so a long command in the other pane still raises its dot.
- The project picker's green terminal badge now also shows while any terminal in that project is running a command.
- Unfinished runs left over from an earlier launch are cleaned up at start-up, so they no longer show as running.
- File open and save dialogs reopen in the folder you used last (Electron 43 stopped doing this on its own).
- Saved secrets use Electron's asynchronous secure-storage API.
- Selected weekdays in the schedule dialog are clearer in every theme.
- Opus-reviewed translations for the new text in all 18 non-English languages.

## Requirements

- macOS 13 or later (Electron 44 dropped macOS 12).

## Testing

- 447 unit tests, a type-check and the i18n check pass. Electron end-to-end tests pass, including a real OpenSSH session against a throwaway local sshd. The packaged macOS arm64 app passes the smoke test. On Ubuntu 26.04 (arm64) the full suite passes, including a Docker OpenSSH session, and the unpacked app and the `.deb` install, launch and remove cleanly.
- New tests cover attention dots, the jump shortcut, scheduled runs with history and catch-up, secret masking in logs and AI requests, lazy-loaded languages and SSH terminals.

## Known limitations

- Windows, Linux x64 and macOS Intel builds were not hand-tested on Electron 45 before release.
- Linux arm64 is a `.deb` only. The arm64 AppImage runtime from electron-builder does not start on a stock Ubuntu install, so it is not shipped. x64 has both the AppImage and the `.deb`.
- Schedules do nothing while the app is closed. Without catch-up, runs missed while closed are skipped.
- Translations are machine-assisted with an Opus review pass; native-speaker review is welcome. Arabic right-to-left layout has not been fully reviewed.
- Agent alerts were tested with the terminal sequences themselves; real Claude Code and Codex sessions were not part of the automated tests.
