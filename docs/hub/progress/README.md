# Progress files

One file per work stream, named for the stream (`deps.md`, `attention-layer.md`). A fresh agent must be able to resume from it without asking anyone. Say what is done, what is not, and how to resume (branch, commands). Start from [the template](_template.md).

|---|---|---|---|
| Dependency security update | [deps.md](deps.md) | done, pending merge | Claude |
